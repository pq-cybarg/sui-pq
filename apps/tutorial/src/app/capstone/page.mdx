# 14. Capstone — mint an NFT backed by Walrus

You've seen each primitive in isolation. The capstone composes them in a single
flow:

1. **Walrus**: upload the user's image content; get a blob id.
2. **Move + dApp Kit**: build a `Transaction` calling `genesis_nft::mint(name, desc,
   walrus_url, recipient)` and sign with the user's wallet.
3. **Sui**: validators mint the NFT object, transfer it to the user, and the
   `Minted` event lands on the indexer.

Three protocols, one click. This is the canonical pattern for "decentralized
asset" apps: blob storage on Walrus, ownership + metadata on Sui, optionally
gated by Seal.

## The full client code

```tsx
import { Transaction } from '@mysten/sui/transactions';
import { WalrusHttpClient } from '@sui-gen/walrus-client';
import { useActiveAddress, useSignAndExecuteTransaction, useSuiClient } from '@sui-gen/wallet-kit';

const walrus = new WalrusHttpClient();

async function mint(name: string, desc: string, imageContent: string) {
  // 1. Walrus upload
  const { blobId } = await walrus.put(imageContent, { epochs: 5 });
  const imgUrl = walrus.url(blobId);   // canonical aggregator URL

  // 2. Build the mint tx
  const tx = new Transaction();
  tx.moveCall({
    target: `${PKG}::genesis_nft::mint`,
    arguments: [
      tx.pure.vector('u8', Array.from(new TextEncoder().encode(name))),
      tx.pure.vector('u8', Array.from(new TextEncoder().encode(desc))),
      tx.pure.vector('u8', Array.from(new TextEncoder().encode(imgUrl))),
      tx.pure.address(recipient),
    ],
  });

  // 3. Sign + execute via wallet
  const res = await signAndExecute({ transaction: tx });
  await client.waitForTransaction({ digest: res.digest, options: { showObjectChanges: true } });
  // res.objectChanges contains the new NFT id, ready to display
}
```
